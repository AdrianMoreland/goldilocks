Merrion Gold design system

Import the library, compose designs from it, and export a design for code. It builds real Figma components, variables and text styles from the repo's design tokens and UI code.

Settings and how it works

Put items onA "Design system" page, or the page you are on

Variables and text styles are always created or updated first, because everything else binds to them. Layouts are built from instances of components and blocks; any that are missing are created automatically. Compose builds a design from a spec using only library components and tokens. Export saves the selected frame, or the library, as JSON so a design can be turned into code and checked for drift. Items marked "no builder yet" exist in the code but are not drawn by this plugin.
