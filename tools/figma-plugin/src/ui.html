Merrion Gold design system

Pick a group, tick what to bring in, then Import. It builds real Figma components, variables and text styles from the repo's design tokens and UI code.

Settings and how it works
Theme for what you importLight or dark colour mode on new frames

Variables and text styles are always created or updated first, because everything else binds to them. Layouts are built from instances of components and blocks; any that are missing are created automatically. Items marked "no builder yet" exist in the code but are not drawn by this plugin.
